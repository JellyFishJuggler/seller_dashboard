# Apparel Seller Business Playbook

This playbook covers the business issues specific to selling clothing on a marketplace: size and colour variants, size-wise inventory, content, returns from fit problems and fashion seasonality. Guidance is general; platform listing requirements for apparel (mandatory attributes, image rules) must be confirmed from official sources (KB-24). Examples are illustrative.

## 1. What makes apparel different

- Fit uncertainty: buyers cannot try the item, so size and fit drive returns.
- Variants multiply stock complexity (style × size × colour).
- Demand is seasonal and trend-driven.
- Content must convey fabric, fit and look through photos and text alone.

## 2. Size variants and size-wise inventory

Demand is rarely equal across sizes. Typical best-selling sizes are middle ones, but this depends on the product and buyers. Measure demand per size from the seller's own orders.

Problems:
- Product shows "in stock" because one size remains, while best-selling sizes are gone.
- Overstock of extreme sizes while core sizes stock out.

Practices:
- Track stock and orders by size (variant level).
- Build a size curve from your own sales history, not assumptions; restock according to it.
- Watch broken size runs: when core sizes disappear, conversion and perceived choice drop.

## 3. Stockout prioritisation by size

Rank size-level stockouts by daily orders × contribution (KB-09). A stockout of a core size of a bestseller is high priority; an extreme size of a slow style is low. Restock core sizes first, and consider reducing extreme-size depth.

Example (illustrative): Style K sells 10/day: M 3, L 3, S 2, XL 1.5, XXL 0.5. If M and L are out, 6 of 10 daily orders are exposed. Restock M and L first.

## 4. Size charts and fit information

- Provide a size chart with body measurements (chest, waist, hip, length) and garment measurements where possible, in cm and inches.
- State fit (regular, slim, relaxed) and model height and size if using model photos.
- Make sure the size labels match the chart and the actual garment.
- Check supplier consistency: different batches can differ in measurement.

## 5. Size mismatch returns: investigation

When size-related returns rise:
1. Break returns by style, size and reason ("too small", "too large", "doesn't fit").
2. Check the direction: if "too small" dominates in one style, the garment may run small.
3. Compare actual garment measurements to the chart and to the listing.
4. Check for supplier or batch changes.
5. Check whether a size chart exists and is visible.
6. Check whether size options were relabelled or mapped incorrectly.
7. Compare returns on older versus newer orders.
Actions: correct the chart, add "runs small/large" notes, add model details, fix labels, change supplier or batch, request size feedback in reviews through allowed means.

## 6. Colour variants and images

Colour mismatch causes returns. Photograph in natural light; avoid over-editing; show swatches; mention colour names clearly. Keep colour variants stocked by actual demand.

## 7. Fabric and material descriptions

State composition (for example cotton, polyester blend), fabric feel, stretch, transparency, care instructions and shrinkage. Do not claim a fabric you cannot verify. Wrong fabric claims drive returns and reviews.

## 8. Apparel catalogue quality

- Clear title (type, fit, fabric, neckline, sleeve, gender).
- Several images including full length, close-up, back, detail, and in-use.
- Accurate attributes (colour, pattern, occasion).
- Size chart.
- Care instructions.
Platform rules apply.

## 9. Seasonality and fashion demand

- Season windows (festive, wedding, summer, winter) shape demand; plan stock before the peak, accounting for lead time.
- Trends shift quickly; limit depth on trend items.
- Plan end-of-season clearance to avoid dead stock.
- Use prior-year data for the same season when available; otherwise be conservative.

## 10. Realistic scenarios

**Scenario A: size returns rising.** A seller notices returns of a kurti rising. Reasons: 60% "too small". Garment measurements show L is 2 cm smaller than the chart. Fix chart/label; return rate monitored.

**Scenario B: stock shows in-stock but sales fall.** Core sizes M and L are out; the listing shows only S, XL, XXL. Restock M and L; conversion recovers if size was the barrier.

**Scenario C: colour complaint.** A "maroon" dress looks red in photos. Update photos and colour name.

## 11. Questions a KAM should ask

- Which sizes sell best for this style?
- Which sizes are out of stock now?
- What are the return reasons by size?
- Do you give a size chart and garment measurements?
- Did the supplier or batch change recently?
- Is this style seasonal, and when does its peak begin?

## 12. What not to conclude

- Do not assume size returns mean the listing is wrong without checking garment measurements.
- Do not assume a universal size distribution.
- Do not give exact restock quantities without size-level demand and lead time (KB-08).
